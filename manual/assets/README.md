# Screenshots

Named `<chapter-slug>-01.png`, `<chapter-slug>-02.png`, ... matching the order they appear on
each chapter's page (e.g. `02-deploy-server-01.png` is the first screenshot in
[`../02-deploy-server.md`](../02-deploy-server.md)). Shared between the English and Chinese
version of a chapter unless the on-screen text is itself what's being illustrated, in which case
suffix the locale: `02-deploy-server-01.zh-CN.png`.
