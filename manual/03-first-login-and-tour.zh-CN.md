# 首次登录与导航

*[English](03-first-login-and-tour.md)*

从[第 2 章](02-deploy-server.zh-CN.md)结束的地方，你应该已经登录进去了。这一章会在还没有任何
设备的情况下，把控制台的每个区域都过一遍——这样等真的有设备上线之后，你就知道该去哪儿看什么。

## 顶部栏

**截图占位符：** `03-first-login-and-tour-01.png` —— 顶部栏，下面提到的每个控件都在图里能看到。

从左到右：

- **菜单折叠按钮** —— 把左侧边栏收起来只显示图标，省出更多屏幕空间。
- **面包屑** —— 显示你现在在菜单树的哪个位置；也可以点击跳转。
- **主题切换** —— 在浅色和深色模式之间切换。
- **语言切换** —— 内置英文、简体中文、日本語；在这里切换会立刻改变控制台里的每一处文字，不需要
  刷新页面。
- **通知铃铛** —— 一个弹出面板，列出最近的系统通知（比如某个告警触发了），可以标记为已读。
- **账号下拉菜单** —— 你的用户名、账号设置入口，以及退出登录。

## 左侧菜单

### 仪表盘（Dashboard）

登录后的首页。四个统计卡片——设备总数、当前在线设备数、未处理告警数、今天收到的数据条数——外加
一个过去 7 天每日数据量的趋势图。全新安装的情况下，这里所有数字都是 0。

**截图占位符：** `03-first-login-and-tour-02.png` —— 空的仪表盘。

### 数据仓库

两个相关但不同的页面：

- **我的数据（My Data）** —— 你所有的设备，以可搜索的列表或网格形式展示，每一行显示它最新的
  读数和在线/离线状态；可以按关键词或在线状态筛选，把当前视图导出成 CSV，点击某个设备可以进去看
  按字段展开的历史曲线图。
- **监控（Monitor）** —— 选一台设备和一个日期/时间范围，在表格里浏览它的原始历史记录——当你需要
  某个具体时间窗口内的精确数值，而不只是最新读数时，用这个页面。

### 设备管理

- **设备（Device）** —— 完整的设备列表（跟"我的数据"读的是同一份数据，但这里的重点是管理设备
  而不是浏览读数）：改名、启用/停用、删除、下发指令、编辑单个字段的显示设置和告警规则，以及批量
  导入/导出工具——在[第 8 章](08-managing-devices-and-products.zh-CN.md)里详细讲。
- **产品（Product）** —— 只是展示用的名称/描述元数据，对应某个设备型号，按 `pid` 匹配到设备上。
  也在第 8 章里讲。

### 告警（Alert）

一份单一的告警*事件*列表——某条规则触发、或者设备离线的记录——可以按设备和状态（未处理/已解决/
全部）筛选，带一个"处理"操作。告警*规则*本身不在这里配置；规则是按设备、按字段，在那台设备自己的
详情页里设置的（**设备管理 → 设备 → 某台设备 → 详情**）。在[第 10 章](10-alerts.zh-CN.md)里详细
讲。

### 系统（System）

一组管理类页面：

| 页面 | 用途 |
|---|---|
| 管理员（Admin） | 管理其他管理员账号（创建、改角色、停用） |
| 角色（Role） | 定义角色，以及每个角色授予哪些权限（`device:read`、`device:write`、`alert:manage`、`system:manage` 这四个中的哪些） |
| 日志（Log） | 审计日志——任何管理员做过的每一个改动操作，谁做的、什么时候做的 |
| API 密钥（API Key） | 给只读的 `/api/open/v1/*` 第三方接口签发和撤销密钥——见[第 11 章](11-users-roles-and-api-keys.zh-CN.md) |
| 文件（Files） | 上传的文件资源（比如控制台其他地方引用的图片） |
| 字典（Dict） | 字典条目——控制台其他地方用到的共享查找列表 |
| 参数（Params） | 运行时可调的系统参数（比如设备侧接口的限速、离线判定的宽限时间）——在这里改完立刻生效，不用重启 |
| 监控（Monitor，系统） | 服务器健康状况：Go 运行时版本、goroutine 数量、内存占用、运行时长、数据库文件大小 |
| 图标库（Icons） | 当设备没有自定义某个字段的显示图标时，`field1`-`field20` 用到的默认图标库 |

**截图占位符：** `03-first-login-and-tour-03.png` —— 展开的系统（System）菜单组。
